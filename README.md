# 📐 Gridlinez 2.0 — Premiere Pro Safe Zones & Custom Grid Plugin

**Gridlinez 2.0** is an Adobe CEP extension for **Adobe Premiere Pro** (2020+, macOS & Windows) and **After Effects** that places pixel-accurate social media safe zones (**Instagram Reels**, **YouTube Shorts**, **TikTok**) and customizable **Custom Grids & Broadcast Overlays** directly onto your active sequence as a transparent overlay track with just one click. ✨

---

## 🚀 Features

### 📱 1. Platform Safe Zones (`Platform` Tab)
- **Instagram Reels (9:16)**, **YouTube Shorts (9:16)** & **TikTok (9:16)**
- **🎛️ Fully customizable UI details in real time**:
  - 🖼️ Upload your own **profile picture** (`CHANGE PHOTO`) or use the default `G` emblem
  - ✅ **Verified badge** (`VERIFIED` toggle on/off)
  - ✍️ Freely editable **Username** & **Caption**
  - ❤️ **Engagement stats**: Likes, Comments, Reposts / Bookmarks / Remix & Shares
  - 🎵 **Liked by** & **Other Likes**, plus **Audio / Sound title**
- **➕ `Also include custom guide`**: Combines the selected platform overlay with your own custom grid at the same time (just like in the template).
- **💾 Save Preset / Saved Presets**: Permanently save your own platform profiles.

### 📏 2. Custom Grid & Professional Overlays (`Custom` Tab)
- **🔢 Rows & Columns**: Any number of rows and columns (e.g., `3×3`, `4×4`, `12×12`)
- **↔️ Margins (%)**: Percentage-based margins (locked uniformly via `🔒` or set individually for Top, Bottom, Left, Right)
- **📐 Gutter (%)**: Percentage-based column and row spacing (double lines)
- **🎬 Professional Overlays**:
  - `Margin box`
  - `Rule of thirds`
  - `Center cross`
  - `Action safe (90%)`
  - `Title safe (80%)`
  - `Diagonals`
- **🎨 Appearance**:
  - `Opacity (%)`
  - `Line thickness` (automatically scales with sequence resolution, e.g., 1080×1920 or 2160×3840)
  - `Guide color` (Free color picker + Hex input + 8 quick-select color swatches)
- **📂 My Presets**: Save, load, and delete your own grid layouts.

### ⚡ 3. 1-Click Timeline Integration
- **✅ `Apply`**: Renders the overlay in the exact resolution of your active Premiere Pro sequence as a transparent PNG, places it in the `Gridlinez Guides` project bin, and automatically puts it across the entire sequence duration on the topmost video track (`V2`/`V3`).
- **🔄 `Replace existing guide on apply`**: Automatically replaces the existing guide overlay on the timeline when making changes.
- **🗑️ `Remove`**: Cleanly removes the guide overlay from the active sequence with a single click.

## 🛠️ Installation

### 🍎 macOS
```bash
chmod +x install.sh
./install.sh
```

### 🪟 Windows
Double-click `install.bat`.

Afterwards, restart **Premiere Pro** and open it via:
**Window (Fenster) → Extensions (Erweiterungen) → Gridlinez** 🎉
